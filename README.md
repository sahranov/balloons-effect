# Прототип эффекта с шариками

Это локальный интерактивный прототип праздничного эффекта на белом фоне. Использует React и Vite, не требует хостинга, базы данных или авторизации.

Можно открыть `balloons-local.html` двойным кликом: весь код, кнопка и шарики встроены в этот файл, сервер не нужен.

## Что внутри

- `app/BalloonEffect.tsx` - основной canvas-эффект с шариками.
- `app/page.tsx` - экран-пример, поверх которого подключен эффект.
- `app/globals.css` - стили экрана, слоя эффекта и кнопки справа снизу.
- `public/assets/balloon-blue.png` - синий шарик.
- `public/assets/balloon-purple.png` - фиолетовый шарик.
- `public/assets/balloon-white.png` - белый шарик.
- `public/assets/corner-bubble.png` - кнопка/бейдж 80 x 80 px в правом нижнем углу.
- `package.json` и `package-lock.json` - зависимости проекта.

## Как запустить локально

```bash
npm install
npm run dev
```

После запуска открыть:

```text
http://localhost:3001/
```

Сервер слушает только 127.0.0.1:3001. Для новой сборки, включая автономный HTML, выполнить `npm run build`.

## Как работает эффект

- При первом открытии экран статичный.
- По клику на экран запускается волна шариков.
- Дополнительный клик запускает ещё одну волну, не обрывая предыдущую.
- Шарики плавно выезжают снизу, летят вверх и уходят за экран.
- Траектории, задержки, скорость и распределение пересчитываются при каждом запуске.
- Кнопка/бейдж справа снизу не перехватывает клики.

## Что можно забирать в интеграцию

Минимально нужны:

- `app/BalloonEffect.tsx`
- ассеты из `public/assets/balloon-*.png`
- CSS для `.balloon-layer`

Если нужна кнопка повторного запуска как в прототипе, дополнительно забрать:

- `public/assets/corner-bubble.png`
- CSS для `.corner-bubble`
- разметку из `app/page.tsx`

Ключевые параметры движения находятся в `app/BalloonEffect.tsx`:

- `BALLOON_COLUMNS`
- `BALLOON_ROWS`
- `BALLOON_WIDTH`
- `BALLOON_HEIGHT`
- `speed`
- `delay`
- `sway`
- `drift`

Эффект не зависит от конкретной картинки экрана: фон можно заменить на любой интерфейс.
